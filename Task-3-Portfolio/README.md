# SAM AI Technologies - Task 3
## Build Your Own Portfolio Site

This project fulfills Task 3 using HTML, CSS and JavaScript.

### Features
- Responsive personal portfolio
- About, Skills, Projects, Resume and Contact sections
- Smooth scrolling
- Hover animations
- Mobile navigation menu
- Back-to-top button
- Resume download button
- GitHub/LinkedIn links

### How to run
1. Open `index.html` in a browser.
2. Replace `your-email@example.com` with your real email.
3. Replace GitHub and LinkedIn links with your profiles.
4. Put your actual PDF resume in this folder and name it `resume.pdf`.
