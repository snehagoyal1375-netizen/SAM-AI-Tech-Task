# SAM AI Technologies - Task 4
## Music Player using JavaScript

A responsive music player built with HTML, CSS and JavaScript.

### Features
- Play / pause / next / previous controls
- Song title, artist and duration
- Progress bar with seek support
- Volume control and mute/unmute
- Playlist interface
- Add local audio files from the browser
- Automatic next-track playback
- Responsive design
- Light/dark theme toggle

### Run
Open `index.html` in a browser. A small demo track is included.
You can also use **+ Add Songs** to add your own audio files.
